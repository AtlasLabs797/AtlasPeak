## Orden recomendado para un agente

1. `01_App-Architecture`: define alcance, stack, arquitectura, base de datos, auth, APIs y plan de construccion.
2. `02_Design-UI-UX`: define sistema visual, layout, estados, responsive, motion y calidad UI.
3. `03_Frontend-Components`: usa shadcn/ui, Headless UI, Radix Themes, Tailwind y patrones HTML como material de montaje.
4. `04_Implementation-Workflow`: convierte el plan en tareas, spikes y trabajo por subagentes.
5. `05_Security`: revisa secretos, SAST/SCA, auth, OWASP/CWE, supply chain y CI/CD.
6. `06_Testing-QA-Debugging`: TDD, debugging, dogfood de web apps, QA visual y navegador.
7. `07_DevOps-GitHub-Automation`: PRs, issues, code review, workflows GitHub, webhooks y kanban multiagente.
8. `08_AI-Agents-Integrations`: SDKs de agentes, MCP, MLOps, Jupyter e integraciones.
9. `09_Product-Copy-Marketing`: copy, assets IA, prompts visuales y patrones de contenido.
